基本介绍：
----------
这个插件给游戏加一个「MAICA_Mood 本地后端」（在 MAICA 官方前端子模组里切换）
节点在列表里的全名是：MAICA_Mood 本地后端
（注意别和「设置 → 子模组」里的条目搞混：子模组列表里显示的是 MAICA_Mood（本地后端），两个名字指的是同一个插件）
聊天走你自己的 API key
聊天时左上角那条心情是插件加的，不影响别的
平时你不需要管它 —— 装好、填一次 key，就当它不存在

相比官方，本插件增加了关于玩家记忆的冲突处理，并且简单处理了信息时效性
但是不得不提：本插件的记忆落库遵循“宁可漏不可错”的原则，如果你聊天时的句子比较复杂或口语化，不在本地小模型训练的覆盖范围之内，很可能会出现漏过信息的情况，此时还有官方write_memory兜底

经实测如果不在对话中刻意说明自己的信息，事实的落库会比较慢。因此我在子模组页面挂载了一份问卷，用于快速填补基本信息（选填）。这份问卷的内容只会存在你的本地，不会上传到其他地方

由于本插件使用第三方大模型API进行聊天，模型对扮演好“莫妮卡”这个角色难免会有偏差，跟官方模型有一部分差距。我已经尽量让她说话比较像人的同时保留莫妮卡的习惯了，你也可以根据需要自行调整大模型的提示词，方法见下“改她的说话风格（可选）”



安装：
------
0. 先确认已经装好官方 MAICA 前端子模组（ChatSubmod 那套），能正常打开「MAICA 参数与设置」。
   （MAICA_ServerSubmod 不是必须的：API Keys 里那几个输入框本插件会自己注册）
1. 先关掉游戏。
2. 把整个「MAICA_Mood」文件夹放进：
       你的 MAS 文件夹\game\Submods\
   是整个文件夹，不要只挑几个文件复制，也不要改文件夹名。
3. 启动游戏。

第一次启动会慢十几秒（后台程序要初始化），正常。
它还会自动改写 runtime\pyvenv.cfg（插件在修正自带 Python 的路径），这是正常现象。


装的是哪个版本
--------------
Release 里有两个包，功能相同，只有「事实抽取」不同：
    MAICA_Mood_1.0.2.zip          1.56 GB   本地小模型（随包附带）
    MAICA_Mood_1.0.2_lite.zip     246 MB    用你填的服务商做抽取

lite 版不需要额外设置：装好后照常填 API Key，插件会发现没有本地模型，
自动把抽取指向同一个服务商。设置页会多一行黄字提示：
    「事实抽取：使用你填的服务商（本包未附带本地模型……）」

已知差异（289 条真实记录实测）：
    误记率（不该记却记了）   完整版 0.51%  lite 8.94%
    漏记率（该记却没记）     完整版 14.58% lite 13.54%
    （589+100 共 689 条，96 条含正事实；完整版测的是发布包里实际带的 Q6_K 模型）
  也就是说：lite 省空间，代价是偶尔会记下一些不该记的小事。

★ 两个包都不要手动删 extractor 文件夹 —— 想省空间请直接装 lite 版。
  （已发布的完整版没有这个判断，删了本地模型后抽取会静默失败、记忆不落库。）


填 API Key（第一次必做）
------------------------
游戏里：设置 → API Keys

以下是示例（你也可以换别的服务商）：
    服务商 url      = https://api.deepseek.com/v1
    服务商 api key  = sk- 开头的那把 key（也可以只填到「第三方API配置」那一格，两处二选一）
    模型名称        = deepseek-flash

（如果装了 MAICA_ServerSubmod，这几项会显示成「核心服务商 url / 核心服务商 api key / 核心模型名称」，
  那是同一批字段，填哪套名字都一样；本插件不依赖它，没装也能填。）

然后到 设置 → MAICA 官方前端子模组 →「MAICA 参数与设置」→ 服务提供节点，
选「MAICA_Mood 本地后端」

几点说明：
1.key 是你自己的，插件不提供、也不会发给任何人；它存在 MAS 的存档目录（api_keys.json）里。
2.好感度到 100 之后，节点列表里才会出现「MAICA_Mood 本地后端」
3.改完 key 之后要重新进一次天堂树林才会生效。
★4.（重要）切换节点后，若显示服务器未连接，需要回到“MAICA参数与设置”确认“当前用户”显示的有名字；如果超过几秒都显示未连接，就重新连接一次节点


问卷与记忆（选填）
------------------
设置 → 子模组 → MAICA_Mood 里有两个按钮：

    快速填写信息      问卷，一次把基本信息填进去；保存后下次聊天会自动记进她的记忆
    查看已记录的信息  看她记住了你哪些事，也可以逐条删除

问卷答案和记忆都只存在本机 backend\data 里，不会上传。


改她的说话风格（可选）
----------------------
在插件文件夹里放一个纯文本文件就行（UTF-8 保存），
改完重启游戏生效。

    提示词-附加.txt    在她的设定后面【追加】几条你的要求
                       （最常用；原来的设定一个字都不动）
    提示词.txt         整份【替换】聊天用的设定（高级用法，写多少都行）
    提示词-写信.txt    替换"写信"那套设定

提示词-附加.txt 里可以这样写：

    ## 我这边加几条
    - 不要用感叹号。
    - 每次回复不超过三句话。
    - 提到我的时候叫我xx。

几点说明：
1.文件要放在插件文件夹里（和 更新.bat 同一个目录），文件名要完全一样
2.删掉文件 = 立刻恢复默认；写坏了也不怕，删掉重启就行
3.只影响「MAICA_Mood 本地后端」；官方节点用的是它自己的设定，不受影响
4.更新不会动这些文件（更新包里没有它们）；卸载时随整个文件夹一起删
5.提示词真源放在"MAICA_Mood\backend\prompts\"，不建议手动改这里，除非你做了备份


更新
----
插件目录里有「更新.bat」：

    把更新包（.zip）放进插件目录 → 双击 更新.bat → 输入 y

它会先备份她的记忆，再覆盖程序文件。更新完重启游戏即可。
backend\data 不会被覆盖，她记得的事都还在。

其实我不确定未来是否真的会发布更新包，但如果各位真的使用了这个插件，并且找到了bug或者有建议优化的地方，请联系我，我会尽快进行更新


卸载
----
双击插件目录里的「卸载.bat」→ 输入 y。

它会：
  1. 把游戏里的设置还原成官方默认（节点 / 会话长度 / 温度）
  2. 关掉后台的三个程序
  3. 删掉整个插件文件夹
若卸载时未启动游戏，它会先自动拉起游戏以切换节点，等卸载结束后手动退游戏即可

★尽量不要在游戏启动的时候卸载，以避免莫名其妙的bug。

★ backend\data 会被一起删掉 —— 那是她记住的关于你的事，删了不可恢复。
  只影响本地节点，官方节点里的记忆不受影响


你的数据存放位置
------------
    backend\data\    她的记忆（聊天里记住的事、问卷答案）→ 更新保留，卸载删除
    ports.json       端口。一般不用管，被占用时插件会自己换一个
    logs\            出问题时看这里，尤其 logs\update.log


常见问题
--------
1.节点列表里没有「MAICA_Mood 本地后端」
    好感度不到 100；或者装完没有重启游戏；或者文件夹没放完整。

2.切到本地节点后一直没回复
    先确认 key 填在「服务商 api key」或「第三方API配置」里（二选一），url 和模型名也都填了；
    改过 key 的话要重新进一次聊天；还不行就退出游戏重开。

3.屏幕提示「端口被占用，已顺延到 ws=5101」
    正常，插件自动换了端口，不用处理。

4.聊天时风扇很响、内存占用高
    聊天期间后台会跑三个本地程序（提取器内存 1 GB 以上，聊得越长越高，一般不会超过2GB），
    退出聊天或退出游戏会自动关掉；强杀游戏也不会留下进程。

5.想彻底清干净
    卸载.bat /force，然后确认 game\Submods\MAICA_Mood 已经删掉。


运行环境
--------
Windows 10 / 11
在 MAS 1.9.4 上测试通过
磁盘空间约 1.7 GB（含本地模型，不需要另外下载）
磁盘格式建议 NTFS（安装路径不要放在压缩包或网络盘里直接运行）


关于"会不会弄坏游戏"
--------------------
不会。这个插件只往节点列表里加一个节点，不修改游戏本体的任何文件。
卸载后设置会还原成官方默认，和没装过一样。


作者的话
----------
本项目由AI辅助完成，我本人也不太熟悉python语言，如果有莫名其妙的bug，请在论坛联系我进行更新。

为什么要加一层记忆处理？MFocus不是可以完成大部分的记忆需求了吗？

这也是我一开始打算写这个项目的原因之一。通过write_memory写入的记忆，可能会出现时效性差（比如“玩家今天吃了烧鸭饭”，召回时莫妮卡拿到的依然是“今天”，与现实不符）、语义偏移（比如玩家说“我有过敏，不是所有咖啡都能喝”可能会记成“玩家对咖啡过敏”）、信息冲突（比如玩家前后说了完全相反的话）的情况，本插件为了尽量避免上述问题，新增了小模型对玩家fact的处理、信息入库。绝大多数“一时情绪”“明显脱离现实的玩笑”“指代不明”“跟玩家本人不完全相关”的信息都不会入库，且对信息冲突做了简单处理。

本插件中数据库信息来源有五种：knowledge（硬编码的莫妮卡本人信息），player_direct（玩家在对话中或问卷中输入的确定信息）， savefile_field（莫妮卡通过write_memory写入的信息），savefile_derived（存档快照，不会自动更新），player_speculation（玩家在对话中输入的推测类、不确定类信息）。来源权威性按上述顺序进行排序，除knowledge是旁路层，player_speculation是兜底层外，其他三层召回时按权威性排序命中即停。
召回的如果是player_direct中的信息，莫妮卡会拿到“玩家在x天前说过：.......”的提示词，方便辅助判断事实究竟发生在哪一天，缓解时效性差的问题，而savefile_field和savefile_derived是上游存在的字段，本插件不对其作出处理，若发现信息有冲突，请自行到官方前端子模组页面进行修改

最后，感谢你看到这里，祝你身体健康，万事顺心
